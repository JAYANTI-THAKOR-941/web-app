# Course Website — React

React educational website with course data, course listings, home, services, about and contact pages.

## Project structure

- `src/pages/`
- `src/data/coursesData.js`
- `src/components/Card.jsx`
- `src/components/Header.jsx`

## Getting started

```bash
git clone https://github.com/JAYANTI-THAKOR-941/web-app.git
cd web-app
```

Run `npm install` and `npm run dev`. Open the URL shown in the terminal.
